# 星图回航

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-27/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-27)

看清星点路线，按“记好了，回航”，从最后一站倒序点回起点。六段从3点增加到8点，三次失误结束，无失误每段额外加100分。支持Tab/空格、静音、复制成绩。

参考 **Subway Surfers** 的短局、清晰目标和快速重试，将核心挑战原创组合为「逆序路线记忆 + 六段增长 + 共享信号预算」。复玩动力是记忆掌握、无失误奖励和随机新路线；不使用其跑酷、轨道、角色或素材。逆序记忆本身是通用机制，心理钩子尚无真实留存验证。
