# 昼夜邮局

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-26/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-26)

点击邮袋或按1–4投递。同级、昼夜相反的信在袋口合成升级，升级保留来信属性，可触发连锁。每袋3封，20封一局；满袋不可合成时误投扣失误，三次或无路可投结束。

参考 **Gossip Harbor** 的升级期待与空间管理，原创改为「昼夜配对 + 堆叠连锁 + 20次投递」。复玩动力来自规划下一封、连锁升级和挑战邮资纪录；没有复制剧情、订单或素材。通用合成机制不声称全新发明，心理钩子尚未经过留存验证。
