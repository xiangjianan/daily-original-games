# 月秤码头 · 2026-09-30

[立即试玩](https://xiangjianan.github.io/daily-original-games/2026-09-30/) · [总仓库中的源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-30)

把货箱放到左右远近四个吊点，重量乘距离改变月秤刻度。每四箱靠近金色目标获得分数，精确命中有额外奖励；16箱完成一局。参考 Block Blast! 的局面规划与 Subway Surfers 的短局纪录挑战，借鉴完成欲、掌握感与再挑战心理钩子。原创变化为力矩累计、未来三箱预览、四箱交付及逐段收紧安全范围，不使用网格消除或跑酷规则。

随机重量和目标、精确交付奖励、本机最高分是复玩动力；这是设计假设，未做留存验证。

## 操作

点击吊点或键盘1–4；左远/左近/右近/右远分别乘−2/−1/1/2。安全区外扣船体并归零，三次超载结束。每四箱得 max(0,200−目标偏差×20)，零偏差另奖100。音效可关闭，分享按钮复制分数和链接，复制受限时显示文本框。支持手机触摸；无需安装。

纯静态HTML，无构建依赖。直接打开index.html即可。研究、规则与测试见 research.md、design.md、tests.md。
