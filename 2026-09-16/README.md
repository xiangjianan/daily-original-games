# 三色雨庭

[立即试玩](https://xiangjianan.github.io/daily-original-games/2026-09-16/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-16)

点花盆接雨，每盆集齐三色就开花。重复颜色会扣活力；第 13 滴起花盆轮换休眠。30 滴一局，也可按 1/2/3 操作。音效可关闭，成绩可复制分享。

## 今天的机制总结

参考 **Block Blast!** 的直观操作、完成反馈和资源规划，将其转化为原创的「三盆异色收集 + 下一滴预览 + 轮换休眠」。复玩动力来自补齐三色的完成欲、连续开花的加分、自我纪录挑战和随机新局。没有复制网格、形状摆放或行列消除，心理钩子属于设计假设，尚无真实留存数据。
