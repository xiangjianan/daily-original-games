## 同一个仓库按日期累加

从2026-09-30起，历史和后续游戏均保存在本仓库根下 `YYYY-MM-DD/`，游戏入口是该目录的 `index.html`。不再创建每日独立仓库。GitHub Pages 从 main 根目录发布。保留历史游戏，不覆盖同日已完成作品，不强制推送。

每个日期目录保存完整代码、README.md、research.md、design.md、tests.md。开发前核实近期休闲游戏热度并记录来源、日期和数据范围；参考设计思路，原创组合，避免历史重复。每款具有清晰操作、完整循环、计分/目标、结束重开、交互后启动且可静音的音效、链接或成绩分享，兼顾桌面手机。

发布必须实际浏览器测试开始、核心玩法、计分、结束、重开、音效/静音、分享、布局和控制台；提交推送并验证远程SHA、Pages部署与线上可玩后交付。复玩机制及其设计假设必须明确记录，不编造数据或留存结论。每日完成报告在任务中提供中文机制总结、试玩和源码链接。

历史仓库迁移、备份和验证情况见 [迁移记录](migration-2026-09-30.md)。原 games/目录的历史说明保留。
