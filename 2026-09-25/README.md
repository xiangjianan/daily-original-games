# 邻数点心铺

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-25/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-25)

点击相邻两块点心，数字和等于订单即可出炉。周围数字随之加一，每单局面变化；12单一局，三次加错结束。再次点选中点心取消，点不相邻位置改选，不扣分。支持键盘 Tab/空格、静音和成绩分享。

参考 **Royal Match、Candy Crush Saga** 的短目标、连续成功反馈，原创改为「相邻算数配对 + 邻格升温 + 动态订单」。复玩动力是完成订单、保持连续出炉和刷新纪录，没有采用交换三消或参考游戏素材；心理钩子尚未经过留存测试。
