# 借风送星

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-23/) · [仓库](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-23)

点击左、中、右出发道（或键盘 1/2/3），风会改变落点。收星、避礁，每六步靠港计分，18 步一局。可关闭音效、复制成绩分享。

参考 **Subway Surfers** 的路线选择、收集反馈与短局重试，原创改成「风向改变落点 + 货物到港结算」的可思考航行。反复游玩的动力是掌握风向、完成航程、保住货物与刷新个人纪录。区别于参考作品的实时跑酷，也区别于历史三色收集玩法；这些心理钩子尚未通过留存实验验证。
