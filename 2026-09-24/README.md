# 回声织灯

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-24/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-24)

点击一盏灯，同时翻转它和右边一盏，末盏连回首盏。用有限步数匹配目标，完成 6、8、10 盏的三段灯谱。可用 Tab 与空格操作，可静音和复制成绩分享。

参考 **Arrows Puzzle Escape** 的轻操作、规划和短关卡重试，改成「环形双灯联动 + 随机目标 + 省步评分」。复玩动力是补齐图案、掌握规律和刷新步数纪录；没有复制箭头出逃、阻挡关卡或素材。双灯翻转属于通用逻辑机制，本作原创体现在具体组合与实现，心理钩子尚未经过留存测试。
