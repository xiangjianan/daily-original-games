# 苔格花房

[在线试玩](https://xiangjianan.github.io/daily-original-games/2026-09-28/) · [源码目录](https://github.com/xiangjianan/daily-original-games/tree/main/2026-09-28)

点空格种两格苔藓，切方向可向下种。拼满2×2收获；每六次长石头，18次后结算，无处可种则提前结束。支持R切换、Tab/空格、静音和成绩分享。

参考 **Block Blast** 的空间规划与清空反馈，原创改为「双格种植 + 方圃收获 + 周期石头」。复玩动力是完成方圃、应对新布局和挑战高分；不复制形状库、行列消除或素材，心理钩子尚无留存实验。
